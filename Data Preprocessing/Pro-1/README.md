# 📊 Data Profiler Project

## 🚀 Overview
This project demonstrates the complete Data Analysis workflow using Python, Pandas, SQL, JSON, API integration, Data Cleaning, Exploratory Data Analysis (EDA), and Data Profiling.

## 📂 Project Structure

- 📓 `Data_Profiler.ipynb` — Main Jupyter Notebook
- 📄 `student_performance.csv` — Dataset
- 📄 `student_performance.json` — JSON Data
- 🗄️ `student_performance.db` — SQLite Database
- 📊 `Data_Profiler.html` — Profiling Report

## 🎯 Conclusion

This project successfully demonstrated the complete Data Analysis workflow using Python and related data science libraries. The dataset was collected from multiple sources, including CSV, JSON, SQLite Database, and REST API, and then processed through data cleaning and preprocessing techniques.

Exploratory Data Analysis (EDA) was performed using various visualizations such as histograms, boxplots, correlation heatmaps, and pair plots to identify patterns, trends, and relationships within the data. Data profiling further provided valuable insights into data quality, missing values, statistical distributions, and feature correlations.

Overall, this project highlights the importance of data acquisition, cleaning, visualization, and profiling in transforming raw data into meaningful insights that support data-driven decision-making.
